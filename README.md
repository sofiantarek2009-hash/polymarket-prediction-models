## Overview

Statistical modeling suite built to forecast binary and categorical event contract outcomes on **Polymarket**, identifying mispriced implied probabilities relative to underlying event fundamentals and market microstructure signals.

## Empirical Backtest Summary

- **Historical Accuracy:** **~78% outcome prediction accuracy** across historical backtests
- **Baseline Comparison:** Consistently **outperforms naive market-implied and baseline statistical predictors**
- **Focus Areas:** Event outcome probability calibration, market pricing inefficiencies, and quantitative backtest validation
